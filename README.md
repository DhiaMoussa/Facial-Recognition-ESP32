
# Facial Recognition System – ESP32-CAM

## Présentation du projet

Développement d'un système embarqué de reconnaissance
faciale utilisant ESP32-CAM, Python et OpenCV.

Le système permet d'acquérir des images, de détecter
des visages et de les comparer avec une base de
données de référence.

## Objectifs

- Acquérir des images avec ESP32-CAM.
- Détecter les visages présents dans les images.
- Traiter les images avec Python et OpenCV.
- Comparer les visages avec une base de données.
- Transmettre les informations sans fil.

## Réalisations techniques

- Configuration du module ESP32-CAM.
- Acquisition et traitement d'images.
- Détection des visages.
- Extraction des informations nécessaires.
- Comparaison avec les références enregistrées.
- Transmission sans fil des données.

## Technologies utilisées

- ESP32-CAM
